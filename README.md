# Graphics Module (Neon Vibes)

Модуль визуальных эффектов для Roblox. Разработан для использования в связке с лаунчером [Menu Visual & Optimization](https://github.com/a32435629-collab/menu-visual-and-optimization).

## 🚀 Что делает этот модуль?
Этот скрипт заменяет стандартную, скучную графику Roblox на стильный **Киберпанк / Неон**:
- **Космическое небо**: Заменяет стандартный Skybox на глубокий космос.
- **Неоновая атмосфера**: Добавляет фиолетовый туман и легкое свечение (Bloom).
- **Цветокоррекция**: Делает цвета более насыщенными и сочными.
- Модуль написан так, чтобы **не убивать FPS** (в отличие от стандартных теней, которые мы отключили в модуле `render`).

## 📂 Структура проекта
Проект собирается из нескольких модулей с помощью `build.bat`:
- `src/sky.lua` — установка космического неба.
- `src/effects.lua` — настройка тумана, Bloom и цветокоррекции.
- `src/init.lua` — точка входа (запускает всё остальное).
- `dist/graphics.lua` — **готовый файл**, который скачивает и запускает лаунчер.

## 🛠️ Как использовать
1. Откройте лаунчер `Menu Visual & Optimization`.
2. Нажмите кнопку **«2. Restart Graphics»**.
3. Скрипт автоматически скачает `dist/graphics.lua` с этого репозитория и применит настройки.
